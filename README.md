# Docket Lens

Where public comments on FDA's discussion paper on generative AI-enabled medical devices ([FDA-2026-N-7874](https://www.regulations.gov/docket/FDA-2026-N-7874/comments)) focused, compared with the comment from the NSF AI Research Institute on Interaction for AI Assistants (ARIA).

The site lets you define "focus" three ways and redraws the charts for each:

- **FDA questions.** Which of the discussion paper's 26 questions a comment substantively addressed, whether or not it cited them by number.
- **Paper sections.** Risk assessment, premarket evaluation, postmarket monitoring, and other topics.
- **Topics beyond the questions.** Themes commenters raised that none of FDA's questions asked about.

You can also filter by commenter type and weight comments by page count.

## Repository layout

| Path | What it is |
| --- | --- |
| `index.html` | The site. Static, no build step. |
| `data/comments.json`, `data/meta.json` | The data the site reads, generated by `pipeline/merge.py`. |
| `pipeline/codebook.md` | The coding rules every comment was coded against. |
| `pipeline/codes/*.json` | One coded record per comment. This is the hand-checkable core of the project. |
| `pipeline/aria.json` | ARIA's comment, coded the same way, used as the reference. |
| `pipeline/pull.py` | Downloads comment text and metadata from the Regulations.gov API. |
| `pipeline/merge.py` | Joins the raw comments with the codes, groups topic tags, and writes `data/`. |

## Updating

FDA posts comments after review, so the docket keeps growing for a while after the comment period closes.

1. Get a free API key at [api.data.gov/signup](https://api.data.gov/signup).
2. `REGULATIONS_GOV_API_KEY=... python pipeline/pull.py` downloads every posted comment into `pipeline/raw/` (not committed).
3. Code any new comments against `pipeline/codebook.md` and add them to `pipeline/codes/`. Attachments are hosted on `downloads.regulations.gov`, which blocks many cloud servers, so read them from a normal browser.
4. `python pipeline/merge.py` regenerates `data/`. New topic tags that match no group show up in its output as "Other"; add a pattern in `TOPICS` if they deserve their own group.
5. Commit and push. GitHub Pages republishes the site.

## Caveats

Coding was done with AI assistance against the codebook and should be treated as approximate. Commenter types come from Regulations.gov's own category field; comments with no category were assigned a type from their content and are marked "inferred". A few comments filed under one category read as coming from another (for example, individuals filed as Device Industry); the site keeps the filed category. Check a comment's original text before quoting or citing it.
